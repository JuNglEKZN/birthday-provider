# Brand Asset Brief

HACS publication requires brand assets. Final icon creation is intentionally deferred until the integration has a working v0.1 UI, but the design constraint is already defined.

## Name

Birthday Provider

## Concept

A minimal symbol combining:

- contact/person
- calendar/birthday marker

Avoid:

- Apple logo
- iCloud logo
- Google logo
- Home Assistant trademark-derived house mark
- cake clip-art aesthetic if it harms legibility at small size

## Requirements

- simple silhouette
- recognizable at small HACS icon size
- neutral enough to remain valid when Google Contacts arrives in v0.2
- no provider-specific branding
- transparent background variant
- square master

## Repository target

Final asset must satisfy the current HACS custom-integration brand requirements before v0.1.0 release.
